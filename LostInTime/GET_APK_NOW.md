## 💻 **Method 3: Command Line Build (Advanced)**

If you have access to a Linux/Mac terminal:

```bash
cd LostInTime

# Install Java 8+ first
sudo apt-get install openjdk-8-jdk  # Ubuntu/Debian
# or
brew install openjdk@8              # macOS

# Try to build
./gradlew assembleDebug
```
